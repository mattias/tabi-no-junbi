# 旅の準備 · Japanese Learning Setup

A step-by-step guide to setting up Anki, a pop-up dictionary and tools that turn anime, games and books into flashcards. It's written for people without technical skills.

**Read it here: https://mattias.github.io/tabi-no-junbi/**

The guide covers:

- the JSchoreels FSRS-7 version of Anki and the add-ons that work with it
- Onigiri (fixed for that Anki version), the Kiku card design and the Hachidori pop-up dictionary
- extra tools: Irodori Audio, Anki Miner, GameSentenceMiner, mpv with hachidori-mpv and immersion-mpv, readers, and Immersion Dashboard
- moving from Migaku, and filling in missing fields with backfill-anki-yomitan
- other languages

It's a plain HTML, CSS and JavaScript page with no build step. Your ticks are saved only in your own browser.

The page design is fan-made and inspired by 葬送のフリーレン. It isn't affiliated with the series or with any of the tools listed.
